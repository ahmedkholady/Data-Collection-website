# Data Collection Website

A web-based data collection and search system for phone-number records.

> **Status:** Under active development.

## Technology Stack

- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **ORM:** Prisma

## Project Structure

```text
Data-Collection-website/
├── Front-end/    # React + Vite application
├── Back-end/     # Node.js + Express REST API
├── Database/     # Database scripts and configuration
├── .gitignore
└── README.md
```
